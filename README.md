# UH AI Hackathon

## Frontend map simulator

Run these commands from the repository root (`uh-ai-hackathon/`):

```sh
npm install
npm run dev
```

Vite serves the app from `frontend/`. The package manifest, lockfile, Vite configuration and Prettier configuration live at the repository root.

```sh
npm run build   # production files in frontend/dist/
npm run preview # preview the production build
npm test        # frontend tests
```

See [frontend/README.md](frontend/README.md) for the simulator, map data, address search and interaction details.
